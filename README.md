Lead story: a tanker hit by a mine in the Strait of Hormuz, with diplomacy in Washington, a strike in Gaza, a Russian strike on Zaporizhzhia, and NATO on space defence.

## How to run

```sh
python3 -P -s main.py
```

This writes `/output/entry.png` (and a local copy `entry.png`). The program uses only PIL and the Python standard library, with fonts bundled in `fonts/`, and is deterministic: repeated runs produce byte-identical output.
